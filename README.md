# Тренажёр ЕГЭ по английскому

Полные варианты ЕГЭ в браузере для самопроверки: аудирование с записью, чтение, грамматика и лексика, письмо и устная часть с записью голоса. Задания 1–36 проверяются автоматически, письмо (37–38) и устную часть ученик оценивает сам по критериям. Ответы хранятся в localStorage браузера, на сервер ничего не отправляется.

| Страница | Файл |
|---|---|
| Главная со списком вариантов | `index.html` |
| Проверка микрофона | `mic-test.html` |
| Движок тренажёра (общий для всех вариантов) | `assets/trainer.js`, `assets/trainer.css` |
| ЕГЭ 2027, Тест 1 | `v/ege2027-1/` |

## Как добавить вариант

1. Скопируйте папку `v/ege2027-1/` под новым именем, например `v/ege2027-2/`.
2. Замените аудио в `audio/` (аудирование одним файлом, вопросы задания 3 устной части отдельными файлами) и картинки в `img/`.
3. Перепишите `data.js`: тексты заданий, ключи и `id` варианта. Формат данных виден по `v/ege2027-1/data.js`.
4. Добавьте ссылку на вариант в `index.html`.

Аудио сжимается в моно 48 кбит/с: `ffmpeg -i in.mp3 -ac 1 -ar 24000 -b:a 48k listening.mp3`.
